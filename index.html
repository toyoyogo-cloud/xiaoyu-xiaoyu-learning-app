平台說明

本平台提供自行編寫的練習題、答題解析、錯題本、收藏、測驗紀錄與本機備份。題目為學習示範內容，並非教育部官方完整題庫或歷屆試題原卷。各校進度與教材版本可能不同。

跨裝置帳號同步、家長管理及 AI 即時出題需要額外的安全後端與資料庫；目前不會在公開前端存放任何 API 金鑰。
