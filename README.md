# 小宇小妤智慧學習測驗

第二階段：全學段、全科目題庫架構與測驗功能。

## 目前功能
- 國小一年級至六年級、高中高一至高三年級選擇
- 國小科目：國語、數學、生活、自然、社會、英語
- 高中科目：國文、英文、數學、歷史、地理、公民、物理、化學、生物、地球科學
- 基礎、進階、挑戰難度篩選
- 逐題練習、模擬考（最多 10 題）、本次錯題重練
- 即時答案回饋與解析
- 暱稱模式及本機學習紀錄（瀏覽器 localStorage）；免登入模式可直接測驗

## 題庫說明
目前每個學段／科目先提供基礎、進階、挑戰示範題，作為功能與題庫結構的起始版本。年級可選擇，但同一學段內的題目目前尚未依每一個年級的冊次、版本或單元完全拆分。題目為自行編寫的教學示例，不是教育部官方題庫，也不是歷屆考題原卷。後續應依年級課綱、教材版本及單元逐步擴充，並進行教師校對。

## AI 出題
前端已預留 AI 智慧出題的產品規劃說明；真正的生成式 AI 出題尚未啟用。正式串接需要安全的後端 API 服務與金鑰管理，不能將 API 金鑰寫在公開的前端程式碼中。
