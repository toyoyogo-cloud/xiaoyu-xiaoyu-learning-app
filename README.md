# 小宇小妤智慧學習測驗

第一階段：建立可在瀏覽器執行的測驗 APP 原型。

## 目前功能
- 國小、高中年級選擇
- 國語／國文、數學、自然、英文、地理、歷史科目選擇（依學習階段顯示）
- 免登入測驗
- 暱稱模式與本機學習紀錄（使用瀏覽器 localStorage）
- 即時作答回饋、解析與成績統計

## 開啟方式
直接以瀏覽器開啟 `index.html`。若要公開網址，可在 GitHub Repository 的 Settings → Pages 將部署來源設為 `Deploy from a branch`，分支選 `main`、資料夾選 `/ (root)`。

## 注意
目前為第一階段前端原型，題庫是示範題；暱稱與紀錄只保存在使用者目前的瀏覽器，不是跨裝置雲端帳號。正式題庫、題目管理與雲端會員紀錄將在後續階段擴充。
