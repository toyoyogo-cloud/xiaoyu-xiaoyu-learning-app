# 小宇小妤智慧學習測驗

一個以 GitHub Pages 部署的繁體中文響應式學習測驗網站，支援國小、國中、高中學習階段。

## 網站

https://toyoyogo-cloud.github.io/xiaoyu-xiaoyu-learning-app/

## 目前功能

- 國小一年級至六年級、國中七至九年級、高中高一至高三年級選擇
- 依學習階段、年級選擇科目、難度、單元及題數
- 已分批新增多批年級專屬題目，持續擴充；各批新增數量詳見下方題庫擴充紀錄
- 逐題練習、模擬考、錯題重練、收藏題目練習
- 模擬考倒數計時、提前交卷、作答進度
- 即時回饋與答案解析；模擬考結束後統一檢討
- 自動收錄錯題、收藏題目、答對重練後移除錯題
- 暱稱與訪客模式
- 測驗歷程、各科平均表現、最高正確率
- 學習資料 JSON 匯出與匯入備份
- 手機、平板、桌面響應式介面
- 無第三方套件依賴，可直接以靜態網站方式執行

## 題庫與課程範圍

題庫採自行編寫的示範題，包含基礎、進階、挑戰等層級，並附答案與解析。curriculum-map.json 是國小、國中、高中各年級的單元索引草案。

**重要範圍說明：** 年級、科目及單元選單已建立；目前已開始依年級提供專屬題目，但部分科目仍以學段共用示範題提供，並非每一個年級、每一個單元都已達到完整教材覆蓋。題目不是教育部官方完整題庫，也不是歷屆試題原卷。實際課程會因年度課綱、學校進度與教材版本而異，正式教學或考試前請以學校教材核對。

## 資料與隱私

暱稱、測驗紀錄、錯題與收藏目前只儲存在使用者目前瀏覽器的 localStorage。不同裝置或瀏覽器不會自動同步；清除瀏覽器網站資料也可能造成資料遺失。請使用「資料管理」定期匯出 JSON 備份。

目前不是雲端會員系統，沒有跨裝置同步、家長管理或教師管理後台。

## AI 即時出題

AI 即時出題尚未啟用。正式啟用需要安全後端、金鑰管理、題目審核、濫用防護及資料政策；不可將 AI API 金鑰放入公開前端程式。

## 部署

Repository → Settings → Pages → Build and deployment → Deploy from a branch → Branch 選 main、資料夾選 /(root)。

網站更新後，GitHub Pages 可能需要一段時間重新部署；若仍看到舊版，請稍後重新整理或清除網站快取。


## 安裝與離線使用

此版本加入 PWA manifest、應用程式圖示與 Service Worker。首次連線開啟網站後，瀏覽器會快取主要頁面與必要資源；之後在支援的瀏覽器中可加入主畫面，並在已快取資源可用時離線開啟。首次載入仍需網路，且瀏覽器可能依儲存空間政策清除快取。

本次新增高中物理、化學、生物與地球科學題目，並補充國小及國中不同年級的語文、數學、自然、社會與公民題型。
