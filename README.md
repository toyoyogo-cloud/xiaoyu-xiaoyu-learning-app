# 小宇小妤智慧學習測驗

持續開發中的網頁學習測驗平台。

## 已整合功能
- 國小一年級至六年級、高中高一至高三年級選擇
- 國小：國語、數學、生活、自然、社會、英語
- 高中：國文、英文、數學、歷史、地理、公民、物理、化學、生物、地球科學
- 基礎、進階、挑戰難度篩選
- 逐題練習、模擬考（最多 10 題）、錯題重練
- 即時作答回饋與題目解析
- 暱稱模式及本機測驗紀錄（瀏覽器 localStorage）
- 個人學習分析：測驗次數、平均正確率、最高正確率及錯題數

## 題庫現況與限制
目前每個學段／科目提供少量示範題，用於驗證測驗流程與功能。年級選單可選擇，但題目尚未完整依每個年級、冊次、教材版本與單元拆分。示範題為自行編寫，不是教育部官方完整題庫，也不是歷屆考題原卷。正式擴充時需依課綱與指定教材逐單元編寫、校對答案及解析。

## 資料與帳號
暱稱與測驗紀錄目前只存在使用者當前瀏覽器的 localStorage。不同裝置或瀏覽器不會自動同步；這不是安全驗證的雲端會員系統。正式家長管理與跨裝置同步需建立後端資料庫及身分驗證。

## AI 出題
AI 出題尚未啟用。需先建置安全後端、金鑰管理、題目審核與內容安全流程；不得把 API 金鑰放入公開前端程式。
